# 📘 The Open Source Audit – Git Analysis Project

This project is a comprehensive analysis of Git, a widely used open-source version control system. It explores the origin, philosophy, licensing, Linux integration, and role of Git in the open-source ecosystem, along with practical implementation using shell scripting. :contentReference[oaicite:0]{index=0}

---

## 📌 Project Overview

The objective of this project is to understand not only how Git works, but also why it was created and how it supports modern software development. The report combines theoretical concepts with hands-on Linux-based experimentation.

---

## 🔍 Topics Covered

- Origin and problems Git was designed to solve  
- GNU General Public License (GPL v2)  
- Ethics of open-source software  
- Git’s integration with Linux systems  
- Role of Git in the FOSS ecosystem  
- Open Source vs Proprietary comparison  

---

## 🧪 Practical Work

The project includes implementation of shell scripts demonstrating real-world usage:

- System Identity Report  
- FOSS Package Inspector  
- Disk and Permission Auditor  
- Log File Analyzer  
- Open Source Manifesto Generator  

---

## 🛠 Technologies Used

- Git  
- Linux (Ubuntu)  
- Bash / Shell Scripting

## 🎯 Learning Outcomes
